### ID 0：名のない明日

死者の城が沈んだ朝、黒鉄蓮は誰の名も書かれていない道標を見つけた。歴史に残る勝者になることより、隣を歩いた者たちを忘れないことを選んだ。

別れは約束を消さなかった。旅の荷には仲間から受け取った手紙がある。蓮は自分の足で、まだ誰も奪っていない明日へ歩き出した。

### ID 1：茜さす旗

城の外で、茜は戦のために掲げていた旗を畳んだ。「今度は、帰る場所を一緒に作りたい」。蓮がうなずくまで、彼女は静かに待っていた。

二人が選んだのは、名を競う合戦ではなく荒れた畑を耕す日々だった。夕暮れに交わす言葉は少ない。それでも、翌朝も隣にいるという約束は毎日新しくなった。

### ID 2：雪解けの水

澪は雪解けの水を手ですくい、これが城の見せる幻でないことを確かめた。蓮も同じ冷たさに触れ、二人で笑った。

傷ついた旅人が訪れる小さな宿に、二つの灯りがともる。澪は誰かを救うために自分をすり減らす夜を少しずつ手放した。蓮は、彼女が休む時間を一緒に守ると決めた。

### ID 3：名を呼べる朝

朧は最後の影が消えるのを見届けてから、自分の名を蓮に告げ直した。命令でも合図でもなく、ただ呼んでほしい名だった。

朝市で隣を歩く二人を、追う者はいない。朧は時折、遠回りを選ぶ。帰り道がいくつあっても同じ家へ戻れることを、そのたびに確かめるように。

### ID 4：余白の祈り

紫苑は歴史を書き換えていた帳面の最後に、何も書かなかった。「これからのことは、決めつけずにおきましょう」。蓮はその余白を閉じずに残した。

二人の暮らしには、失敗も迷いも訪れる。けれど誰かの運命として押しつけられた日々ではない。相談し、選び直し、互いの意思で同じ明日を迎えた。

### ID 5：風を通す窓

楓は古い屋敷の窓をすべて開けた。城へ向かった夜には言えなかった望みを、今は自分の声で蓮へ伝えられた。

二人は互いの居場所を狭めないと約束した。離れて過ごす日にも、帰ってから聞かせたい話が増えていく。風の通る部屋で、次の旅の支度を一緒に整えた。

### ID 6：消えない火

火乃香は工房の炉へ、新しい炭を足した。何かを壊すためではなく、明日の暮らしに使う道具を作るための火だった。

蓮が手伝うと、火乃香は遠慮なく失敗を笑い、うまくできた時には真っ先に見せた。城の夜を越えた二人の間で、その火は競うものから分け合うものへ変わっていった。

### ID 7：二つの湯呑み

千景は旅支度の横へ、二つの湯呑みを並べた。戦いのない朝にどう振る舞えばよいか、二人ともまだ慣れていなかった。

言葉にできない日は、急いで答えを出さない。蓮と千景は、黙って隣に座る時間も約束の一部にした。湯気が消えるまでの静けさを、今度は誰にも奪わせなかった。

### ID 8：夜明けの鈴

小夜の鈴が、城の崩れる音を追い払うように鳴った。蓮はその音に合わせて、彼女が差し出した手を取った。互いの意思を確かめる言葉は、もう戦の号令にかき消されない。

次の祭りで小夜は、帰らぬ者への祈りと、生きている者の明日を舞った。見守る蓮へ笑いかけると、夜明けの風が二人の間を通り抜けた。
