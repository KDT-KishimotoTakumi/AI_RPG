# 罠・破壊可能地形

2026-09-24 利用者承認。FR-016、T013/T017/T018。

- 罠は全員に見え、敵味方共通。通過時に固定10ダメージ、防御・回避無効。1回発動で消滅する。確定前に被害を表示し、仲間AIは罠を含めて自滅する経路を避ける。
- 移動力以内の経路は罠被害最小→歩数最短で選ぶ（利用者承認）。同条件は固定順で再現する。経路と被害を表示してから確定する。
- 主人公の致死移動は警告を了承して実行可能（利用者承認）。HP0になった罠のマスで停止し、残る罠は発動させない。他の味方が生存していれば次の手番へ進む。
- 移動予告は実際の停止位置までの経路・HPを上限とした被害・戦闘不能を示す。無効/古い操作・取消では罠も乱数も状態も変わらない。
- 初期の人物・壁・障害物と罠は重ねない。生成検証は罠を通らない領域の接続も要求し、罠を踏まなければ目的へ到達できない配置を退避対象にする。
- 破壊可能地形は耐久20の障害物。移動・射線を遮り、通常攻撃は必ず命中して攻撃力分の耐久を削る。1行動を消費し、耐久0で平地になる。
- 障害物への通常攻撃も射程・途中の遮蔽・手番・行動済み・状態世代を検査する。無効操作では状態・乱数を変更せず、確定命中で命中乱数を消費しない。耐久は0未満にならない。
- 障害物と壁・人物の重複配置は不正。生成時は破壊に頼らず全通行可能マスを接続させ、固定戦場への退避を維持する。
- 受け入れ検証: 遮断→攻撃予告→耐久減少→破壊→通行/射線回復、敵側の攻撃、射程外・遮断・行動済み・古い操作、100シード、実画面の操作を確認する。
- 障害物の基本ルール・表示・生成に続き、罠の移動経路・予告・仲間AI安全判定・生成検証を実装する。特殊技による地形変化・AIによる積極的な地形破壊は後続工程。
