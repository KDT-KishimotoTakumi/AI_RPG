# 戦場生成の実装契約

2026-09-24。FR-015/017/018、SC-003。既存の基本戦闘に対する初期実装。

- 幅・高さを各8～12でシードから決定し、壁・高低差・遮蔽・耐久20の障害物・罠を配置する。人物の初期位置とその近傍、および導入用の通路は平坦に保つ。人物編成と初期位置はEncounterが供給する。
- 通行可能マスが一つの領域として接続し、全参加者・救出対象へ地形上到達可能であることを検査する。通行判定は戦闘の4方向・壁・高低差規則と共有する。占有は初期地形検査では無視し、実戦で検査する。
- 戦闘開始済み扱いで勝敗が決まる配置は拒否する。現行の通常攻撃の保守的な合計被害上限が各生存味方のHP未満であることを要求し、初期の回避不能な全滅を避ける。
- 生成試行は最大8回。失敗ごとに同一乱数列を進め、上限後は平坦な12×12固定戦場に退避する。固定戦場も同じ検証を通す。固定戦場でも成立しない入力は明示的に拒否する。
- 技術検証用に試行上限0～8と候補生成器を注入できる。0は直接固定戦場を検証する経路であり、通常のプレイは8を使う。状態・乱数・試行回数・退避の有無を再現可能にする。試行ごとに親乱数から子シードを1つ派生し、生成用と戦闘用の乱数列は分離する。
- 本編は生成結果を戦闘へ接続し、生成/固定への切替を画面に表示する。失敗経路のE2Eでは検証用ボタンで不正な候補生成器を注入して8回の検証失敗を発生させ、固定戦場上で通常の移動・攻撃が可能なことを確認する。
- 障害物と罠を通行領域から除外し、破壊や罠被害に頼らない接続を検査する。新規正式戦闘は使用可能技能と先行する敵の回復・強化・解除を含む安全検査を使い、必要なら敵の開始位置を移動力と攻撃技能射程に従って調整する。人物の能力値・旧API・保存済み戦場は維持する。現行の検証は将来の全コンテンツでの目的達成を保証するものではない。

## 生成の安全検査項目（GS-124、FR-015～018・SC-003）

証跡は `Tests/Unit/` の単体試験。「GenSafety」は GS-124 で追加した `GenerationSafetyTests.cpp`（実戦編成の全4役割×全3難易度×100シード、通常/正式の両経路）。件数は `docs/VALIDATION.md` の GS-124 を参照。

| 性質 | 状態 | 証跡 |
|---|---|---|
| 寸法8～12・タイル数一致 | 検証済み | Generation（100シード×3目的）、GenSafety |
| 壁・高低差・遮蔽・障害物・罠の生成と、全種を同時に含む戦場 | 検証済み | Generation（壁/高低/遮蔽）、Terrain/Trap（100シード）、GenSafety（全種同時・値域・壁と他地形の非重複） |
| 全参加者が地形上で相互に到達可能（罠・障害物を通らない） | 検証済み | Generation（分断/段差拒否）、Terrain/Trap、Encounter、GenSafety（全参加者の全組合せ） |
| 目的達成可能: 全敵/救出対象/城主へ主人公が到達 | 検証済み | Generation（3目的・簡易編成）、GenSafety（実戦編成のEliminate/Rescue/DefeatLord、生成後のSurvive） |
| 初期即死回避（正式技能・先行支援込み） | 検証済み | Generation、EnemyCharacterSkills、FormalEncounter、Cavalry/Fox/MidBoss/Oni、GenSafety（HP1/8/25の味方も含む） |

| 同一シード再現（参加者順序非依存を含む） | 検証済み | Generation、Encounter、GenSafety（Checkpoint全体一致） |
