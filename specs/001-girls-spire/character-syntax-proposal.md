# 正式技能の構文属性・確認案

2026-11-01。**利用者が属性ルールを一括承認済み。本体接続は未完了。** 効果・数値はcharacter-abilities-proposal.mdで承認済み。
新しい正式技能の起/承/転/結の属性だけを追加確認する。

- 通常の攻撃技能は結、弱体を付ける攻撃技能は転、回復/味方強化は承。
- 全ての個人必殺は既存規則と同じ結（回復型必殺も含む）。
- 通常攻撃/移動/待機/作戦対象変更等の既存属性と、承認済み20連携/専用8連携の条件を変更しない。
- 旧形式の戦闘は元の技能効果/属性を維持し、新規開始する正式技能の戦闘から適用する。
