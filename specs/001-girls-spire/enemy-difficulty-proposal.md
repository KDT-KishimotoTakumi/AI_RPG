# 難易度別敵思考（承認済み・未接続）

FR-053の具体的な比較条件。2026-11-04、利用者が「表を一括採用する」を選択。TDDで接続する。

## 維持する規則

- 敵HPは既存の初級80%・中級100%・上級120%。能力/技の効果/命中/行動回数/CD/召喚/遮蔽生成は変更しない。
- 妖狐のHP50%以下への回復優先、鬼武者の有利な強撃、骨忍の承認済み退避、射手の射程内射撃など、承認済みの敵種別規則を先に適用する。
- 攻撃/射線/範囲/移動/罠は既存の予測APIで判定する。新しい属性相性やダメージ補正は導入しない。
- 乱数抽選を増やさず、同点は固定順。新規戦闘だけに適用し、旧保存戦闘の思考は途中変更しない。

## 標的選択

| 難易度 | 合法な攻撃候補の比較順 |
|---|---|
| 初級 | 使用者から攻撃中心までの上下左右距離が短い → 対象IDが小さい |
| 中級 | 下記の連携妨害点を加えた期待ダメージが大きい → 対象IDが小さい |
| 上級 | 予測ダメージが現在HP以上となる命中対象の命中率合計が大きい → 中級と同じ評価が高い → 攻撃中心の対象の次の手番が早い → 対象IDが小さい |

- 期待ダメージは現在の実装と同じ、全命中対象の「命中率×min(予測ダメージ,現在HP)」の合計。弱い防御/回避をこの既存予測で評価する。
- 連携妨害点は、未解決のプレイヤー側連携履歴に参加する人物を1人以上攻撃する候補へ＋500を1回。履歴のSequenceがResolvedSequence以下なら対象外。複数人に当たっても重複加点しない。
- 上級の戦闘不能予測は命中を保証しない。範囲攻撃では既存予測の全対象を集計する。
- 次の手番は現在の行動順から、死亡者を除いて循環した距離で比較する。素早さ/行動順自体を変更しない。

## 攻撃できない場合の移動

- 初級・中級は既存の敵種別の接近を維持する。
- 上級は到達先へ移動を仮適用し、そこから既存ルールで可能になる攻撃を上記の上級評価で比較する。射線/範囲は既存予測を使う。
- 同評価なら、経路の罠被害＋到達先での既存PotentialHostileDamageが少ない → 敵対者との最短距離が短い → Y/Xが小さい位置を選ぶ。
- 罠で移動中に戦闘不能となる経路は上級の候補から除外する。攻撃可能な移動先がなければ既存の接近を同じ除外条件で行い、なければ待機する。
- 行動後の骨忍の退避は専用の承認済み比較を維持する。移動・攻撃の仮適用で実戦の乱数を消費しない。
