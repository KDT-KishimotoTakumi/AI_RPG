# 通常スキルの初期実装

2026-09-24。共通ルール・開発用2技を提示後、利用者から「作業を行ってください」と継続指示。FR-026/028、T013/T015/T018/T023の一部。

- 技は1行動を消費する。クールダウン2は使用後の自分の手番2回で使用不可、3回目から再使用可能。使用手番の終了では減らさない。戦闘開始時は0へリセット。
- 開発用「強撃」: 通常攻撃と同じ射程・射線・命中判定。攻撃力に8を加えて防御を計算する。クールダウン2。通常攻撃と同様に障害物も攻撃できる。
- 開発用「応急手当」: 射程3・射線必要、自分または同陣営の生存者のHPを20回復。最大HPまで、確定成功、クールダウン2。満タン・戦闘不能・異なる陣営は対象外。
- 無効対象・不所持・クールダウン中・行動済み・古い操作は状態、乱数、行動、クールダウンを変更しない。外れた強撃も有効な行動としてクールダウンを消費する。
- 移動との前後関係は既存の役割ルールを維持。予告と実行は同じ判定を使う。回復は乱数を消費しない。
- 仲間の支援は使用できる回復を通常攻撃より優先して候補化する。その他の作戦には強撃候補を追加。所持技と残りクールダウンを画面に表示する。
- 周回プレビューの味方に開発用2技を装備する。正式な人物固有技・成長による取得・必殺・強化/弱体化・難易度別敵思考の完成とはしない。
- 検証: 予告一致、命中/外れ、回復上限・無効対象、各クールダウン境界、他者手番で不変、新戦闘リセット、役割別移動、仲間支援、安全性、UI操作をTDDで確認。
