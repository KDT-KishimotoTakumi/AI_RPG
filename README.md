# Girls Spire

仲間への作戦意図と信頼による解釈、行動の「起・承・転・結」から生まれる連携構文を核とした、
戦国怪異グリッドターン制ローグライクRPGです。

UE5.7.4で動く開発版です。12日間の経路・救出・戦闘・成長と、保存・中断再開を実装しています。
人物/敵コンテンツの残るAI・素材、立ち絵差分、恋愛の総合検証、音の最終調整と残る設定反映、配布検証は未完成です。承認済みの通常/専用交流と後日談本文は接続済みです。

独自の城背景・濃紺と金のメニュー・人物駒とHPバー・多層ステレオBGMを追加しています。戦闘や保存の規則は維持しています。

タイトルの「設定」から文字サイズと独立音量・各フラグを保存できます。文字サイズは周回・戦闘・人物情報へ反映し、次回起動も保持します。初期BGMと確認/打撃音を再生し、保存した独立音量と消音を反映します。最終ミックス・正式差分・配布確認は開発中です。 音声を利用できない場合は画面下に通知し、音なしでも設定やゲームを続けられます。音量0の設定だけでは通知しません。

戦闘盤面は陣営・移動先・通常攻撃可能対象・危険を記号でも示します。右の操作欄の下部で「盤面：単色」と「敵被害上限の予測」を切り替えられます。予測は実際の敵行動や命中を確約しません。文字を拡大して画面に収まらない場合は、盤面側をマウスホイールでスクロールしてください。

新規戦闘では承認済みの正式18技能・9個人必殺/8絆100強化・専用8連携を使用します。開始時の絆を固定し、旧保存戦闘は従来のルールで再開します。

妖狐の回復優先と絡新婦の移動力低下を初期接続しました。HP割合に基づく自己・友軍回復と、命中から対象の手番終了までの移動−2（下限0・行動後移動にも適用）を処理し、中断保存も維持します。ボス2体の承認済み戦闘挙動と未救出者4人の最終戦再登場も接続済みです。内容全体・配布検証は未完成です。

呪詛僧を5日目以降の一部編成へ接続しました。通常攻撃の命中で、対象の次の手番終了まで攻撃力が4下がります。弱体は重複せず、通常攻撃・技・必殺へ反映します。戦闘中の中断再開でも状態を維持します。

鬼武者を5日目以降の一部編成へ接続しました。移動2・射程1・攻撃16で、通常攻撃より予告ダメージが高い時は強撃を選びます。クールダウン中は通常攻撃へ切り替えます。周回セーブはv16で、旧v2〜v15を読み込めます。

骨忍を5日目以降の一部編成に接続しました。攻撃前に移動していない場合は攻撃後に退避し、罠を含む予測被害を優先して退避先を選びます。致死罠の経路は選びません。

騎馬亡者を5日目以降の通常系戦闘に初期接続しました。実際の直線移動が3マス以上なら、その手番の通常攻撃力＋6。スキルは対象外で、準備状態は中断再開でも保持します。通常敵全体は引き続き実装中です。

主人公と仲間8人の通常立ち絵の初期素材を接続しました。戦闘の盤面下に編成メンバーの画像・名前・HP・手番を表示し、戦闘不能は減光と文字で示します。画像を読み込めなくても名前・HPと操作を維持します。正式な状態差分と配布同梱の確認は後続です。

交流ノードで加入済みの相手→返答→絆の増減予告→確定を操作できます。確定前は取消可能です。絆は戦闘中の信頼と同じ値で、通常ゲームでは次回起動にも引き継ぎます。会話は開発用で、最新の検証状態はdocs/VALIDATION.mdを参照してください。

連携と他者への回復で絆を獲得します。盤面下に連携・援護の内訳を表示し、戦闘終了後「経路へ戻る」で反映します。敗北でも保持し、戦闘途中の信頼は変えません。各仲間1戦につき連携最大＋5、援護最大＋3、絆上限100です。通常ゲームではディスクへ保存します。

商店では商品→対象→予告→購入確定を操作できます。購入せず退出も可能です。傷薬を持ち込んだ戦闘では「傷薬を使う」→自身か隣接する味方→予告→確定で使用します。商店・傷薬の最新全体検証はVALIDATION.mdを参照してください。

開発用の強撃・応急手当を味方に追加しました。技→対象マス→予告→確定で使用し、再使用待ちを表示します。仲間の支援作戦は回復を優先します。正式な人物固有技は未実装です。

実戦で勝利して周回画面へ戻ると、受取人→三択→効果確認→取得へ進みます。受取人と三択は変更できません。薙ぎ払い・遠当て・癒しの術は1人につき追加3個まで、能力強化は周回内で累積し、次の戦闘へ反映します。通常ゲームでは受取人・抽選済み候補・乱数状態も保存します。

実戦勝利で開始時の味方全員（戦闘不能者を含む）が経験値を得ます。通常/救出100・強敵150・ボス200、200ごとにレベルアップし上限10。1レベルにつき最大HP＋5・攻撃＋1・防御＋1を回復処理より先に反映します。成長分のHP＋5を別途回復はしません。仲間は加入時の主人公と同レベル・経験値0。周回画面にレベル・経験値（上限はMAX）・成長合計を表示します。

既存編成のHP・負傷は次戦へ引き継ぎます。勝利時は生存者20%回復、戦闘不能者は負傷後の最大HP50%で復帰。休息では「全員50%回復」または「1人を1段階治療」を選び、予告を確認して確定します。取消ではイベントを消費しません。治療だけでは現在HPは増えません。新規加入者の初期HPは従来どおりです。

初期連携3種を実戦へ接続しました。移動・待機の「起」から、通常攻撃や開発用技を組み合わせると、2/3/5人でゲージ10/20/40が蓄積します。盤面下に戦闘内ゲージ、直近の参加者と成立理由を表示します。承認済み20種と発見の恒久保存は実装・検証済みです。正式技能18種・個人必殺9種と絆100強化・専用連携8種は新規通常戦闘で有効です。旧セーブの戦闘は途中変換しません。

ゲージ50以上で「開発用個人必殺」を選び、敵のマス→命中・威力・消費の予告→確定で発動できます。行動1回と50を消費し、攻撃力＋20。外れても消費します。仲間も手動指定で、AIは自動使用しません。「結」で連携が成立すれば消費後に加算します。人物ごとの正式必殺は未実装です。

全員必殺は主人公＋仲間4人が全員生存し、発動者から縦横合計4マス以内、未行動、ゲージ100で使用できます。「全員必殺」→敵マス→各対象の予告→確定で、中心と上下左右の敵へ攻撃力＋40。発動者の行動1回と100を消費し、他4人の手番は残ります。取消・無効対象は消費なし、外れも消費。一部でも外れると連携履歴を中断し、全命中時は消費後に「結」の連携成立分を加算します。

## 通常ゲームの起動

PowerShell 7で `./tools/play.ps1` を実行します。通常構成へビルドしてから、画面サイズを自動解決してフルスクリーンでゲームを開きます。タイトルの「ゲームを終了する」からマウスで終了できます。戦闘中は「保存して中断する」でタイトルへ戻ってから終了します。エディタ/PIE/プレビューにプロセス終了先は渡しません。
導入済みのUE5.7と起動先は環境から検出します。保存先はUEのProjectSavedDir配下のSaveGamesです。
この開発環境の通常起動では `Saved/SaveGames`、PIEでは `Saved/DevelopmentSaves` を使います。

確定操作と敵味方の各行動を自動保存します。「保存して中断する」からタイトルへ戻り、次回起動の「中断した周回を再開」で続行します。
再開時に中断を消費し、以後の異常終了では直近の確定状態から復旧します。保存失敗中は同じ内容の再試行のみ可能です。
本体の破損はバックアップから復旧し、両方が破損した場合は損失確認後に対象側だけ初期化できます。元ファイルは保存先のCorrupt配下へ保全します。
取引記録だけが破損し、周回・恒久データが正常かつ同じ確定世代の場合は「取引記録の修復を確認」から元記録を保全して再構築できます。確定世代が食い違う場合は、正常な最新共通世代の周回・恒久ペアを予告し、戻る可能性と失われる変更を確認してから復旧できます。本体/バックアップと取引記録の存在する原本をすべて保全します。共通世代なし・内容衝突・未来版・読込失敗では上書きせず停止し、原本変更時は再確認します。有効な未完了取引は既存の再生を優先します。

絆・専用交流の完了・後日談の本を恒久保存します。絆80以上の加入済み仲間との交流で「二人の約束」を選び、最終勝利後に条件達成者全員または単独の後日談を選べます。確定すると周回を終え、タイトルの「後日談の本」から再読できます。旧形式の絆・専用交流は新形式へ引き継ぎます。図鑑・外見の恒久保存、正式な物語全体・素材・設定は開発中です。

## 周回画面のプレビュー

プレビューは保存サービスを使わず、検証用の結果入力を表示します。

PowerShell 7で `./tools/build-unreal.ps1` の後、`./tools/preview.ps1` を実行します。
エディターからはコンソールで `GirlsSpire.Preview` を入力しても開けます。
難易度・武器選択、救出経路、12日間の進行、結果画面を操作できます。
固定シード42を使用します。戦闘イベントで「戦闘を始める」を選ぶと、移動先選択→経路・被害予告→移動確定→対象選択→命中予告→攻撃確定→向きを選んで待機を操作できます。敵は自動で行動し、実戦の勝敗・救出を周回へ反映します。
進行確認用の「検証」ボタンも併設しています。仲間の手番では攻勢・護衛・支援・妨害と対象を選び、予告した候補から行動を委ねます。周回から始める実戦の信頼は絆と同値で、任意変更できません。単独戦場のテストだけに検証用信頼変更を残しています。人物別性格・正式固有スキル・正式イベント・保存は未実装です。

戦場は幅・高さ各8～12で自動生成し、接続と味方の初期安全性を検査します。8回失敗すると検証済み12×12固定戦場へ切り替えます。「検証：生成を失敗させ固定戦場へ」でこの経路も試せます。人物の初期位置は仮配置のままです。
マス内の「高」は標高、「遮」は遮蔽を表します。人物のマスはHPを表示します。
「障20」などは破壊可能障害物の残耐久です。クリックすると確定命中と耐久減少を予告し、「攻撃を確定」で削れます。耐久0で平地になり、通行と射線が開きます。
「罠10」は通過時に10ダメージを与えて消える罠です。経路は移動力以内で罠被害最小→歩数最短の順に選び、移動前に取り消せます。致死移動には専用の了承ボタンを表示し、途中で倒れるとそこで停止します。仲間は罠と敵攻撃を合算して致死となる移動を選びません。

## 基盤テスト

PowerShell 7とVisual Studio 2022のC++ビルドツールを使用します。

```powershell
./tools/test-core.ps1
./tools/build-unreal.ps1
./tools/test-unreal.ps1
./tools/test-unreal.ps1 -UI -Filter 'GirlsSpire.UI'
./tools/test-resume.ps1
./tools/test-runtime.ps1
# 音声有効の通常操作と別プロセス再開
./tools/test-runtime.ps1 -Audio
# 実フルスクリーンで通常操作・音声付き再開を確認
./tools/test-runtime.ps1 -Audio -Fullscreen
```

テストの失敗・ビルドエラーは終了コード非0になります。[検証記録](docs/VALIDATION.md)。

カバレッジの初回準備と計測（ダウンロードは約940MB、展開先はSaved/Tools）:

```powershell
./tools/setup-coverage.ps1
./Tests/Tools/CoverageGate.Tests.ps1
./tools/test-coverage.ps1
```

行・関数・分岐をそれぞれ90%以上で判定します。計測後に通常構成へ戻すには
`./tools/build-unreal.ps1` を実行してください。周回プレビューのUI操作試験は実装済みですが、
基本戦闘の救出・全滅もUI試験済みです。全仕様を含む戦闘とGauntletによる製品版E2Eは未完了です。
